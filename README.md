# 🎲 Dados Monopoly

App web para **tirar dos dados al azar** y ver el resultado. Ideal para jugar al Monopoly (o cualquier juego de mesa) sin dados físicos.

## 🌐 Jugar online

Una vez desplegada, la app queda en:

**https://francoagnic.github.io/Dados-monopoly/**

## Qué hace

- Tira **dos dados** con animación de sacudida.
- Muestra el valor de cada dado y la **suma total**.
- Avisa cuando salen **dobles** (los dos dados iguales) 🎉.
- Funciona en celular y computadora, sin instalar nada.

## Uso local

Abrí `index.html` con doble clic en cualquier navegador.

## Deploy

El deploy es automático con **GitHub Pages** mediante GitHub Actions
(`.github/workflows/deploy.yml`). Cada push a `main` vuelve a publicar la app.
